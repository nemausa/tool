# nvim 操作速查

适用于当前 NvChad 配置。除特别说明外，先按 Esc 进入普通模式。
`空格 fw` 表示依次按空格、f、w。

## 搜索与文件定位

| 快捷键 | 操作 |
| --- | --- |
| 空格 ff | 按文件名查找文件 |
| 空格 fw | 全局搜索代码，带结果预览 |
| 空格 fs | 打开可保留的全局搜索、替换面板 |
| v 选中文字，再按空格 fs | 全局搜索选中内容 |
| 空格 fr | 打开搜索面板并定位到替换输入框 |
| /关键词，然后回车 | 搜索当前文件 |
| n / N | 下一个 / 上一个匹配项 |
| * | 向后搜索光标下的完整单词 |
| 空格 fb | 查找已打开的缓冲区 |
| 空格 fo | 查找最近打开的文件 |

Telescope（空格 ff、fw 等）：Ctrl+j / Ctrl+k 选择结果，回车打开，Esc 关闭。
Workspace Search（空格 fs）：输入关键词后按 Esc，j / k 逐个打开结果，回车进入目标位置。
小写 q 隐藏搜索面板，保留缓冲区；大写 Q 关闭搜索面板并删除其缓冲区。

## 代码跳转

| 快捷键 | 操作 |
| --- | --- |
| gd | 跳到定义 |
| gD | 跳到声明 |
| gr | 查找引用 |
| K | 查看签名、文档 |
| Ctrl+o | 返回上一个跳转位置 |
| Ctrl+i | 沿跳转记录前进 |

定义、声明、引用和悬浮文档需要语言服务器正常工作；C++ 使用 clangd。
终端可能把 Ctrl+i 与 Tab 视为同一个键；当前配置将普通模式 Tab 用于切换缓冲区。
遇到该冲突时，用 `:execute "normal! \<C-i>"` 沿跳转记录前进。

## 缓冲区

| 操作 | 命令或快捷键 |
| --- | --- |
| 切换下一个 / 上一个缓冲区 | Tab / Shift+Tab |
| 关闭当前缓冲区 | :bd |
| 关闭所有缓冲区，保留 nvim | :%bd |
| 丢弃修改并强制关闭所有缓冲区 | :%bd! |

冒号命令输入后按回车执行。普通关闭遇到未保存修改会报错，可能留下部分缓冲区；
带 `!` 的强制关闭会丢失未保存内容，请确认后再执行。
